# pages-demo-assets

ハンズオン `/pages-demo` 用の共有画像ホスト（Nano Banana / Gemini 3 Pro Image で生成した住宅写真）。
GitHub Pages で配信し、テンプレートから絶対URLで参照する。**参加者は画像生成不要**。

公開ベースURL: `https://daimaru-d.github.io/pages-demo-assets/images/`

差し替えたい場合は、同じファイル名（hero/house1〜3/event/column.jpg）で置き換えるか、
daimaru-skills の `pages-demo/assets/gen_images.py`（Nano Banana）で再生成する。
